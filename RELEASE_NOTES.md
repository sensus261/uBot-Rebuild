# uBot — GF 26.1.11 release notes

Adapts the walker + bots to the **26.1.11** client. Pairs with the rebuilt `eXLib.mix` (see `../MetinPythonLib-WalkerPath`).

## Crash + regression fixes
- **Teleport key regression** — `Hooks.py`, `Data.py`. After a world reload (death→teleport, map change, channel switch) the recreated game window's `interface` was `None`, so **I / V / C stopped toggling** inventory/character windows (ESC and the on-screen buttons still worked). The game-window hook used to self-unhook after the first window, so it never re-participated in teleport-recreates. It's now **persistent** (recursion-safe via `CallOriginalFunction`; the shortcut/stream thread is created once), and the permanent `_pinWindow` window-retention (a leak + focus-stealer) was removed.
- **Position reads** — `OpenLib`, `ShopSearcher`, `StoneCompass`, `AutoHunting`, `Radar`, `Settings`, `Buffbot`. Switched every bot from `chr.GetPixelPosition` (returns **NaN** on 26.1.11) to `eXLib.GetPixelPosition`. A NaN coordinate silently breaks all distance math (StoneCompass "none in range", AutoHunt won't approach, shop scan crashes).

## Bots
- **Trading Glass / Shop search** — `ShopSearcher.py`: full-map A\* sweep with checkpoints, working class filter, NaN guards, and **Stop now halts the character immediately** (cancels the in-flight move, like EnergyBot).
- **Stone Compass** — `StoneCompass.py`: reload-safe; metin / ore / boss detection via eXLib; added to `/rah`.
- **Auto pickup** — `Pickup.py` (new): walks to the closest eligible ground item and collects it via `eXLib.SendPickupItem` (needs the rebuilt `eXLib.mix` whose `SendPickupItem` calls the client's own pickup function). Toggle from the hackbar Pickup button / F8, or enable "Pickup" in the Auto-Hunt window to collect drops between fights. Per-item blacklist, `PHASE_GAME`-only, NaN-guarded. Replaces the stubbed `Settings.PickUp()`; Settings now only delegates.
- **Auto-hunt** — `AutoHunting.py`: level-filtered acquisition + focus/skill logic on eXLib positions; reload-safe.
- **Auto-hunt window** — `AutoHunting.py`: the Potions section is now **one row** (HP, SP + 4 spare inputs) and the window is ~108px shorter; saved `pot_N_val` keys for the removed slots are ignored. How auto skill decides what to cast is written up in `docs/AUTOHUNT-SKILLS.md`.
- **Auto-hunt after teleport** — `AutoHunting.py`: `BotBase`'s Frame-gate stamp (`Data.time_BotBase_generalTimers`) is now zeroed on world re-entry, on Start, and whenever `app.GetTime()` goes backward. A stamp from the old map's clock kept `Frame` (and the existing timer rebase inside it) blocked, so Start did nothing after a warp. Not yet verified in-game.
- **Pickup window sizing** — `Pickup.py`: list rows now scale with the screen height (about half of it; 5 rows minimum = the old size) and a grip at the bottom-right corner resizes the window height by dragging (applied on release; saved as `PickupListRows`). Window position is kept across a resize.
- **Energy bot** — `EnergyBot.py`: dynamic inventory sizing, clock-reset-safe timers, and `GetDialogAnswerCount`-based dialog auto-pick (second-to-last = Open Shop) **with the "I have Weapon Shop mission" checkbox as fallback** (active until the event-mgr RVA is re-derived on eXLib side).
- **Auto-hunt movement smoothing** — `Movement.py`, `AutoHunting.py`, `Pickup.py`. Fixes the "runs to the next group, turns back for a moment, resumes" stutter (sometimes 3–4 times in a row). (1) A new path no longer starts at a waypoint the character has already run past: leading waypoints behind the char are dropped (`[MOV] skipped N passed waypoint(s)` in the trace), and intermediate waypoints count as reached at 90 units instead of 40. (2) Buffs no longer stop the run once per buff: due buffs are batched while standing before a far approach, and a buff that comes due mid-run waits for melee (only one that is more than `BUFF_MAX_DEFER` overdue stops the run, once per target). (3) Pickup between kills uses its own radius (`PICKUP_HUNT_RADIUS` 800, not the standalone `PickupRange`), skips items behind the hunt's travel direction, and drops an item instead of running back for it. (4) Focus zone and leash are aligned: targets are picked inside huntRange minus attack reach, the leash fires at huntRange + 150, and the walk-back stops at 0.85×huntRange (was 0.5). (5) More human target choice: mobs with packmates nearby score better (`GROUP_BONUS`), and a random 0.2–0.6 s pause before running to a group more than 1000 units away. `Movement` is now reload-safe and in `/rah`. Not yet verified in-game.
- **Manual-intervention-stops-movement** — `OpenLib.py`: while a bot is pathing, moving the character against the commanded direction for ~0.36 s stops the path (`StopMovement` + stops the sweep / EnergyBot driver). Tunable via `MANUAL_STOP_MOVE_EPS` / `MANUAL_STOP_TICKS`.
